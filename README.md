# E-Commerce Sales and Order Management Analysis

##  Project Overview

This project focuses on designing and analyzing an E-Commerce database using MySQL. It manages customer information, product details, orders, order items, and payment transactions.

The project demonstrates how SQL can be used to organize relational data and extract meaningful business insights related to sales performance, customer purchasing behavior, product revenue, and inventory management.

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

##  Database Design

The database consists of five main tables:

1. **Customers:** Stores customer details such as name, email, city, and signup date.
2. **Products:** Contains product names, categories, prices, and available stock.
3. **Orders:** Stores customer orders, order dates, and order statuses.
4. **Order_Items:** Maintains product details and quantities associated with each order.
5. **Payments:** Stores payment modes, transaction amounts, and payment dates.

##  Key Analysis Performed

The project includes 15 SQL queries to analyze:

- Complete order details using multiple JOINs.
- Total revenue generated by each product.
- Revenue generated by product categories.
- Top customers based on total spending.
- Customers who have not placed any orders.
- Products that have never been ordered.
- Inventory value by product category.
- Top customers using Common Table Expressions (CTEs).
- Product revenue ranking using window functions.
- Products priced above the average product price.
- Order value analysis.
- Revenue by payment mode.
- Order status analysis.
- Low-stock product analysis.
- Customer order count.

## ⚙️ How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your MySQL server.
3. Open `project_1.sql` and execute it to create the database and tables.
4. Open `project-data-populate.sql` and execute it to insert sample records.
5. Open `project_queries.sql` and execute the queries to explore the analysis.
6. Review the output in the MySQL Workbench result grid.
